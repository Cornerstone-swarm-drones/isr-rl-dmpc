01 · Motivation

Why Autonomous ISR Swarms?

⚠ The ISR Challenge
  • Single drones have limited sensor coverage & endurance
  • Human operators cannot react at millisecond timescales
  • Modern threat environments evolve dynamically
  • GPS jamming / contested airspace → degraded localisation
✓ Swarm Advantages
  • Parallel area coverage: $N\times$ throughput
  • Redundancy: mission continues despite single failures
  • Distributed sensor fusion over large baselines
  • Cooperative threat intercept & tracking
⚡ Open Research Gap
  • Classical DMPC uses fixed cost weights → suboptimal across diverse mission phases
  • Pure RL: no hard safety guarantees, slow to train for 3-D control
  • ADMM for swarm coordination: convergence guarantees, but needs adaptive cost tuning
  • No existing system combines MARL-adaptive DMPC + ADMM for full ISR pipeline
Our Answer:
MAPPO learns which cost weights to assign at each moment;
DMPC enforces hard safety constraints;
ADMM provides provable inter-drone consensus.

02 · Problem Statement

Formal Problem Definition

Multi-Drone ISR Problem
Given a swarm of $N$ quadrotors operating in a 3-D environment containing unknown targets, find a decentralised control policy $\boldsymbol{\pi} = \{\pi^{(i)}\}_{i=1}^N$ such that:
  1. Maximal area surveillance coverage is achieved within mission time $T$
  2. All targets are detected, classified, and tracked
  3. Each drone maintains a collision-free trajectory: $\|\boldsymbol{p}_i - \boldsymbol{p}_j\| \ge r_{\min}\ \forall i \ne j$
  4. The swarm maintains a desired geometric formation throughout
  5. Control is executed at 50 Hz under computational constraints
Decision Variables (per drone, per step)
$\boldsymbol{u}^{(i)}_t = [a_x, a_y, a_z]^\top$ — commanded acceleration
$\boldsymbol{a}^{(i)}_t = [\boldsymbol{q}_s^{(i)}, \boldsymbol{r}_s^{(i)}]$ — MARL cost scale vector (14-D)
Key Constraints
$\|\boldsymbol{u}_k\|_2 \le u_{\max} = 10\ \text{m/s}^2$ (saturation)
$\|\boldsymbol{p}_k - \boldsymbol{p}_j\| \ge r_{\min} = 5\ \text{m}$ (collision)
$\boldsymbol{x}_{k+1} = A\boldsymbol{x}_k + B\boldsymbol{u}_k$ (dynamics)

Module 1 · Drone State Space

Linearised Triple-Integrator Dynamics

11-D DMPC State Vector
$$\boldsymbol{x} = \underbrace{[p_x,p_y,p_z]}_{\text{pos.}},\ \underbrace{[v_x,v_y,v_z]}_{\text{vel.}},\ \underbrace{[a_x,a_y,a_z]}_{\text{accel.}},\ \underbrace{\psi,\dot{\psi}}_{\text{yaw}} \in \mathbb{R}^{11}$$ Acceleration as a state gives the MPC inertia-awareness, producing smoother trajectories.
Discrete-time dynamics ($\Delta t = 0.02\,\text{s}$, 50 Hz) $$\boldsymbol{x}[k{+}1] = A\boldsymbol{x}[k] + B\boldsymbol{u}[k]$$ Triple-integrator chain: $\boldsymbol{p} \leftarrow \boldsymbol{v} \leftarrow \boldsymbol{a} \leftarrow \boldsymbol{u}$
System matrices $$A = \begin{bmatrix} I_3 & \Delta t I_3 & 0 & 0 & 0 \\ 0 & I_3 & \Delta t I_3 & 0 & 0 \\ 0 & 0 & I_3 & 0 & 0 \\ 0 & 0 & 0 & 1 & \Delta t \\ 0 & 0 & 0 & 0 & 1 \end{bmatrix},\quad B = \begin{bmatrix} 0 \\ 0 \\ \Delta t I_3 \\ 0 \\ 0 \end{bmatrix}$$
Theorem — Controllability
The 9-D translational sub-system $(A_9, B_9)$ is completely controllable. The controllability matrix $\mathcal{C} = [B_9, A_9 B_9, \ldots, A_9^8 B_9] \in \mathbb{R}^{9 \times 27}$ has rank 9 (Brunovsky canonical form). This guarantees a stabilising LQR gain exists.

Module 2 · Extended Kalman Filter

Multi-Sensor State Estimation

EKF Predict Step $$\hat{\boldsymbol{x}}^- = f(\hat{\boldsymbol{x}}, \boldsymbol{u}), \qquad P^- = FPF^\top + Q_{\text{proc}}$$ where $F = \partial f/\partial \boldsymbol{x}$ is the process Jacobian.
EKF Update Step $$K = P^- H^\top (HP^- H^\top + R_{\text{meas}})^{-1}$$ $$\hat{\boldsymbol{x}} = \hat{\boldsymbol{x}}^- + K(\boldsymbol{z} - h(\hat{\boldsymbol{x}}^-))$$ $$P = (I - KH)P^-$$ Kalman gain $K$ optimally weights prior vs. measurement uncertainty.
Adaptive weighting: $R_{s,\text{eff}} = R_s / c_s$ automatically de-weights degraded sensors using confidence score $c_s \in [0,1]$.

Module 3 · Formation Control

Distributed Consensus Protocol & Graph Theory

Communication Graph & Laplacian
Swarm graph $G = (V,E)$: edge $(i,j) \in E$ iff $\|\boldsymbol{p}_i - \boldsymbol{p}_j\| \le r_{\text{comm}}$
Graph Laplacian: $L = D - A_{\text{adj}}$
For connected $G$: $0 = \lambda_0 < \lambda_1 \le \cdots \le \lambda_{N-1}$
Fiedler value $\lambda_1$ governs convergence speed.
Consensus Formation Control Law $$\boldsymbol{u}_i = \underbrace{k_p(\boldsymbol{p}^{\text{des}}_i - \boldsymbol{p}_i)}_{\text{position err.}} - \underbrace{k_d \boldsymbol{v}_i}_{\text{damping}} + \underbrace{k_c(\bar{\boldsymbol{p}}_{\mathcal{N}} - \boldsymbol{p}_i)}_{\text{consensus}}$$ $k_p=2.0,\ k_d=0.1,\ k_c=0.1$
Convergence Theorem
Discrete consensus: $\boldsymbol{x}[k{+}1] = (I - \Delta t k_c L)\boldsymbol{x}[k]$
Converges iff $\Delta t k_c \lambda_{\max}(L) < 2$.
With $k_c{=}0.1$, $\Delta t{=}0.02$: product $= 0.002\lambda_{\max} \ll 2$ ✓ $$\|\boldsymbol{x}(t) - \boldsymbol{x}^*\| \le e^{-\lambda_1 t}\|\boldsymbol{x}(0) - \boldsymbol{x}^*\|$$

Module 4 · Task Allocation

Hungarian Algorithm — Optimal Bipartite Assignment

Linear Assignment Problem (LAP)
Given cost matrix $\boldsymbol{C} \in \mathbb{R}^{m \times n}$ ($m$ tasks, $n$ drones): $$\min_{\sigma}\ \sum_i C[i,\sigma(i)] \quad \text{s.t. } \sigma \text{ bijection}$$ $n!$ possible matchings → Hungarian gives optimal in $O(n^3)$.
Cost Matrix (weighted sum, 5 factors): $$C[i,j] = 0.30\,c_{\text{dist}} + 0.20\,c_{\text{fuel}} + 0.20\,c_{\text{load}} + 0.15\,c_{\text{sensor}} - 0.15\,b_{\text{priority}}$$ Infeasibility: if travel + task time $>$ endurance $\Rightarrow C[i,j] = 10^6$
König–Egerváry Theorem
Minimum-weight perfect matching = maximum dual objective (LP strong duality).
Dual potentials $u[i]$, $v[j]$ satisfy:
$u[i] + v[j] \le C[i,j]\ \forall(i,j)$
$u[i] + v[j] = C[i,j]$ for matched pairs.
Complexity Analysis
VariantTimeUse Case
Hungarian$O(n^3)$$m \le n$
Greedy fallback$O(mn)$$m > n$ (task surge)
For $n=6$, $m=10$: runs in microseconds on-board.
Rectangular matrices: padded to $\max(m,n)^2$ with dummy rows/cols ($C=10^6$) → always square.

Module 5 · DMPC

Distributed Model Predictive Control

Per-drone QP at each time step $t$: $$\min_{\boldsymbol{x},\boldsymbol{u}}\quad \sum_{k=0}^{N-1}\!\Bigl[\boldsymbol{e}_k^\top Q_{\text{eff}}^{(i)}\boldsymbol{e}_k + \boldsymbol{u}_k^\top R_{\text{eff}}^{(i)}\boldsymbol{u}_k\Bigr] + \boldsymbol{e}_N^\top P\,\boldsymbol{e}_N$$ $$\text{s.t.}\quad \boldsymbol{x}_{k+1}=A\boldsymbol{x}_k+B\boldsymbol{u}_k,\quad \|\boldsymbol{u}_k\|_2\le u_{\max},\quad \|\boldsymbol{p}_k-\boldsymbol{p}_j\|\ge r_{\min}\ \forall j\in\mathcal{N}(i)$$
MARL-Adaptive Cost Matrices
MAPPO action vector (14-D per drone): $$\boldsymbol{a}^{(i)} = [\underbrace{q_{s,0},\ldots,q_{s,10}}_{\boldsymbol{q}_s \in \mathbb{R}^{11}}, \underbrace{r_{s,0},r_{s,1},r_{s,2}}_{\boldsymbol{r}_s \in \mathbb{R}^3}]$$ $$Q_{\text{eff}}^{(i)} = Q \odot \text{diag}(\boldsymbol{q}_s^{(i)}),\quad R_{\text{eff}}^{(i)} = R \odot \text{diag}(\boldsymbol{r}_s^{(i)})$$ Scale factors clipped to $[0.1, 10.0]$ → preserves positive-definiteness.
DARE Terminal Cost (LQR)
Unique PD solution $P \succ 0$ to: $$P = Q + A^\top P A - A^\top P B(R+B^\top P B)^{-1}B^\top P A$$ LQR gain: $K = (R+B^\top PB)^{-1}B^\top PA$
Closed-loop: $\rho(A_{\text{cl}}) \approx 0.983 < 1$ → Schur stable
Terminal cost $V_f(\boldsymbol{e}_N) = \boldsymbol{e}_N^\top P\boldsymbol{e}_N$ bounds future cost.
QP Size (1 drone, $N=20$): 291 vars · 220 eq. · 100 ineq. constraints
Solver: CVXPY → OSQP, warm-starting, 10 ms budget

Module 6 · ADMM Consensus

Alternating Direction Method of Multipliers

Global Consensus Problem
$$\min_{\boldsymbol{z}_1,\ldots,\boldsymbol{z}_N}\sum_{i=1}^N f_i(\boldsymbol{z}_i) \quad\text{s.t.}\quad \boldsymbol{z}_i = \boldsymbol{v}\ \forall i$$ Augmented Lagrangian: $$\mathcal{L}_\rho = \sum_{i=1}^N\!\left[f_i(\boldsymbol{z}_i) + \boldsymbol{\mu}_i^\top(\boldsymbol{z}_i-\boldsymbol{v}) + \tfrac{\rho}{2}\|\boldsymbol{z}_i-\boldsymbol{v}\|^2\right]$$ Scaled form: $\boldsymbol{y}_i = \boldsymbol{\mu}_i/\rho$
Three-Step Iterate (per DMPC cycle):

z-update Local DMPC solve (parallelisable): $$\boldsymbol{z}_i^{k+1} \leftarrow \arg\min_{\boldsymbol{z}_i}\!\left[f_i(\boldsymbol{z}_i) + \tfrac{\rho}{2}\|\boldsymbol{z}_i - \boldsymbol{v}^k + \boldsymbol{y}_i^k\|^2\right]$$ v-update Global average (closed form, $O(N)$): $$\boldsymbol{v}^{k+1} \leftarrow \tfrac{1}{N}\sum_i(\boldsymbol{z}_i^{k+1} + \boldsymbol{y}_i^k)$$ Dual update: $$\boldsymbol{y}_i^{k+1} \leftarrow \boldsymbol{y}_i^k + \boldsymbol{z}_i^{k+1} - \boldsymbol{v}^{k+1}$$
Convergence Theorem (Boyd et al. 2011)
For any $\rho > 0$, if all $f_i$ are closed, proper, convex: (1) Primal residual $r_\text{prim}^k \to 0$;   (2) Dual residual $r_\text{dual}^k \to 0$;   (3) Objective $\sum_i f_i(\boldsymbol{z}_i^k) \to p^*$. Linear convergence rate for strongly-convex $f_i$: $\|\boldsymbol{z}^k - \boldsymbol{z}^*\|^2 \le C\cdot\beta^k,\ \beta \in (0,1)$.
Empirically: 3–5 iterations achieve residuals below $10^{-3}$ m.

Module 7 · MAPPO

Multi-Agent Proximal Policy Optimisation

CTDE — Centralised Training / Decentralised Execution
Training: Centralised critic observes joint state: $$V_\phi(\boldsymbol{s}) = V_\phi(\boldsymbol{o}^{(1)},\ldots,\boldsymbol{o}^{(N)})$$ Execution: Each actor conditions on local obs only: $$\boldsymbol{a}^{(i)} \sim \pi_\theta(\cdot\mid\boldsymbol{o}^{(i)})$$ Shared actor (same $\theta$) exploits permutation symmetry.
PPO Clipping Objective: $$\mathcal{L}^{\text{CLIP}} = \mathbb{E}_t\!\left[\min\!\left( \rho_t\hat{A}_t,\ \text{clip}(\rho_t, 1{-}\epsilon, 1{+}\epsilon)\hat{A}_t\right)\right]$$ where $\rho_t = \pi_\theta(\boldsymbol{a}_t|\boldsymbol{o}_t)/\pi_{\theta_\text{old}}(\boldsymbol{a}_t|\boldsymbol{o}_t)$, $\epsilon=0.2$
Full objective: $\mathcal{L} = \mathcal{L}^{\text{CLIP}} - c_1\mathcal{L}^{\text{VF}} + c_2\mathcal{L}^{\text{ENT}}$

Module 8 · Geometric Attitude Control

SO(3) Control — Global, Singularity-Free

Why SO(3) vs. Euler Angles?
Euler angles suffer from gimbal lock (coordinate singularities at ±90° pitch). Geometric control on $\mathrm{SO}(3)$ is globally defined and avoids numerical issues near singular configurations.
Attitude error vector (SO(3) formulation): $$R_e = R_d^\top R, \qquad \boldsymbol{e}_R = \tfrac{1}{2}\text{vex}(R_e - R_e^\top) \in \mathbb{R}^3$$ Geometric PD torque command: $$\boldsymbol{\tau} = -K_{p,\text{att}}\boldsymbol{e}_R - K_{d,\text{att}}\boldsymbol{e}_\omega + \underbrace{\boldsymbol{\omega}\times(J\boldsymbol{\omega})}_{\text{gyro FF}}$$ Gyroscopic feed-forward improves tracking at high angular rates.
Motor Mixing (X-configuration): $$\begin{bmatrix}F\\\tau_x\\\tau_y\\\tau_z\end{bmatrix} = \begin{bmatrix} k_f & k_f & k_f & k_f\\ -k_fL & k_fL & k_fL & -k_fL\\ k_fL & k_fL & -k_fL & -k_fL\\ -k_d & k_d & -k_d & k_d \end{bmatrix} \begin{bmatrix}T_1\\T_2\\T_3\\T_4\end{bmatrix}$$ Motor speed: $\Omega_i = \sqrt{T_i/k_f}$, PWM $= \Omega_i/\Omega_{\max}$
Cascade Control Architecture
DMPC accel. command $\boldsymbol{u}$
→ Position loop: desired $\boldsymbol{a}_\text{des}$ → desired $R_d$
→ Attitude loop: $\boldsymbol{\tau}$ (geometric PD on SO(3))
→ Motor mixing: $[T_1, T_2, T_3, T_4]$

Module 9 · Stability Analysis

Lyapunov · ISS · CBF · Recursive Feasibility

Lyapunov Asymptotic Stability
Candidate: $V(\boldsymbol{e}) = \boldsymbol{e}^\top P\boldsymbol{e}$, $P \succ 0$ (DARE solution)
Under LQR law $\boldsymbol{u} = -K\boldsymbol{e}$: $$\Delta V = \boldsymbol{e}^\top(A_\text{cl}^\top P A_\text{cl} - P)\boldsymbol{e} = -\boldsymbol{e}^\top(Q + K^\top RK)\boldsymbol{e} < 0$$ $\Rightarrow$ Global asymptotic stability of LQR-closed-loop. Stability margin $\approx 0.017$; spectral radius $\rho(A_\text{cl}) \approx 0.983$.
ISS Gain Bound: $$\gamma_\text{iss} = \sqrt{\tfrac{\lambda_\text{max}(P)}{\lambda_\text{min}(P)}} \cdot \tfrac{\|A_\text{cl}\|_2}{1-\rho}$$ Max disturbance for $\varepsilon=1$ m error $\approx$ 1.3 mm/s² — within IMU noise level. ✓
Control Barrier Function (CBF)
Safety function: $h_{ij}(\boldsymbol{x}) = \|\boldsymbol{p}_i - \boldsymbol{p}_j\|^2 - r_\text{min}^2 \ge 0$
CBF condition: $h_{ij}(\boldsymbol{x}[k{+}1]) \ge (1-\alpha)h_{ij}(\boldsymbol{x}[k])$
Linearised affine constraint on $\boldsymbol{u}$: $$-2\boldsymbol{\delta}^\top B_\text{pos}\boldsymbol{u} \le 2\boldsymbol{\delta}^\top\boldsymbol{v} + \alpha h$$ Forward Invariance: if $h_{ij}(\boldsymbol{x}_0)\ge 0$ and constraint holds at every step → $h_{ij}(\boldsymbol{x}_k)\ge 0\ \forall k$.
Recursive Feasibility (Rawlings & Mayne, 2019)
With terminal cost $P$, terminal set $\Omega_f = \{\boldsymbol{e}: \boldsymbol{e}^\top P\boldsymbol{e}\le c\}$, and terminal law $\boldsymbol{u}_f=-K\boldsymbol{e}$: feasibility at $t=0$ $\Rightarrow$ feasibility for all $t>0$ (shift argument).
Implementation note: $\Omega_f$ is not enforced as explicit QP constraint; $P$ acts as soft terminal penalty. Guarantees are heuristic under MAPPO scaling.

04 · Challenges

Technical Challenges

1. Non-Convex Collision Constraints
The constraint $\|\boldsymbol{p}_k - \boldsymbol{p}_j\| \ge r_\text{min}$ defines the complement of a ball — non-convex. OSQP only supports linear constraints. Approach: Treat neighbour positions as fixed parameters per QP solve; use CBF affine reformulation as the theoretically sound alternative.
2. MAPPO-DMPC Stability Gap
DARE terminal cost $P$ computed for fixed $(Q,R)$. When MAPPO scales produce $Q_\text{eff} \ne Q$, the Bellman identity no longer holds → stability guarantees are heuristic. Approach: Scale clipping $[0.1, 10]$ keeps effective matrices well-conditioned.
3. 50 Hz Real-Time Budget
Each drone must solve a 291-variable QP in $<10$ ms. Approach: DPP-compliant CVXPY problem (built once, warm-started), OSQP with $\varepsilon = 10^{-3}$; ADMM adds only 3–5 iterations overhead.
4. Partial Observability in MARL
Each drone observes only 40-D local information; optimal policy requires global state. Approach: Centralised critic $V_\phi(\boldsymbol{o}^{1:N})$ during training reduces gradient variance; shared actor exploits symmetry.
5. Sensor Fusion Asynchrony
GPS at 10 Hz, IMU at 400 Hz, radar asynchronous. State must remain consistent for DMPC. Approach: Three parallel EKFs fused in DroneStateEstimator; adaptive $R_{s,\text{eff}} = R_s/c_s$ de-weights stale sensors.
6. Scalability of ADMM Communication
Each ADMM iteration requires sharing $\boldsymbol{z}_i$ across all drones. Approach: Bandwidth $= N \times K \times d \times 4$ bytes. Default (N=4, K=5, d=3): 240 bytes / step ≪ 1 kbit/s.

Key Contributions

1 MARL-Adaptive DMPC Cost Tuning
Instead of fixed $Q, R$ matrices, MAPPO outputs per-drone scale vectors at every 50 Hz step: $Q_\text{eff} = Q \odot \text{diag}(\boldsymbol{q}_s)$. The controller can dynamically trade off tracking accuracy, energy, and formation keeping. Preserves QP convexity (positive-definiteness) by design.
2 ADMM Consensus for Swarm DMPC
Three-step ADMM iterate couples local QP sub-problems across drones with provable convergence (Boyd et al. 2011) to a globally consistent reference. Communication overhead: just 240 bytes/step for a 4-drone swarm.
3 Full ISR Pipeline Integration
End-to-end system integrating EKF sensor fusion, Bayesian classification, Hungarian task allocation, formation consensus, DMPC, ADMM, MAPPO, and geometric attitude control in a single 50 Hz loop — no ROS2 required.
4 CTDE + Shared Actor Architecture
Centralised critic $V_\phi(\boldsymbol{o}^{1:N})$ during training reduces variance for correlated rewards. Shared actor (same $\theta$ per drone) leverages permutation symmetry, drastically reducing parameter count. Decentralised at runtime.
5 Safety-Aware RL via CBF + Hard Constraints
The RL policy only adjusts cost weights — all hard safety constraints (collision avoidance, actuator saturation) remain inside the QP and are enforced by OSQP regardless of the RL output.
07 · Conclusion

Summary & Future Directions

What We Built
  • Complete MARL-adaptive DMPC framework for 4-drone ISR swarm
  • 10 integrated modules: perception → decision → consensus → control
  • MAPPO-ADMM-DMPC loop running at 50 Hz in PyBullet simulation
  • 3 real-world mission scenarios with full evaluation suite
  • Formal stability analysis: Lyapunov, ISS, CBF, recursive feasibility
Key Takeaways
  • MARL can safely adapt MPC cost weights without breaking convexity
  • ADMM provides elegant, theoretically grounded inter-drone coordination
  • CTDE (centralised training, decentralised execution) is essential for correlated swarm tasks
  • Hard safety constraints in the QP provide a safety layer RL alone cannot
Current Limitations
  • Stability guarantees are heuristic under online MAPPO scaling
  • Terminal set $\Omega_f$ not enforced as explicit QP constraint
  • Collision constraints are non-convex (handled via CBF alternative)
  • Physics model uses small-angle linearisation (valid near hover)
Future Work
  • Explicit terminal set constraint for rigorous recursive feasibility
  • Re-solve DARE online when $Q_\text{eff}$ changes (adaptive terminal cost)
  • Hardware deployment on hector_quadrotor airframe
  • Graph neural network for scalable multi-drone observation encoding
  • Adversarial training for robustness to GPS jamming / communication loss
  • Nonlinear MPC (NMPC) to remove small-angle assumption
